# 规则表怎么改

三张表在 `scripts/rules/`，纯 JSON，改完重跑即生效。代码里没有任何写死的广告词或译名。

---

## ads.json —— 广告与噪声

三个数组，区别在于「删还是留」：

| 数组 | 行为 | 用在哪 |
| --- | --- | --- |
| `drop_lines` | 命中即**整行删除** | 站点水印、纯网址行、页码行、盗版站名 |
| `strip_inline` | 只**剔除行内片段**，保留其余文字 | `正文……（本章未完，请翻页）` 里的括注 |
| `flag_lines` | **保留**，写进 `flags.jsonl` 和报告 | 求票、作者感言、疑似广告——拿不准的都放这里 |

每条格式：

```json
{"name": "规则名", "pattern": "Python 正则", "flags": "i"}
```

`name` 会出现在报告的删除明细里，起个能看懂的名字。`flags` 可选 `i`（忽略大小写）、`m`、`s`。

### 加规则前先想清楚是哪一类

拿不准就放 `flag_lines`。删错了正文，用户很难发现——比多留几行广告糟糕得多。

### strip_inline 之后还会再查一次 drop_lines

剔除片段后如果整行只剩 `（本章完）` 这类残渣，会被二次判定删掉。所以不必为「剔完变空行」单独写规则。

### 自动断行的坑

`drop_lines` 里的正则都按**整行**用 `search` 匹配，不是 `fullmatch`。写 `.*关键词.*` 时注意别太宽——`.{0,12}` 这类长度限制是故意的。

### line_join

```json
"line_join": {
  "end_punct": "。！？…”』」）】》!?~～.．",
  "min_len": 12,
  "max_merged_len": 800
}
```

`auto` 模式先判断原文是不是「一句一行」：抽样 2000 行，若**以句末标点结尾的比例 < 35%** 且平均行长 < 60 字，判定为 `hard_wrap`，才启用合并。正常分段的书不会被碰。

## en2zh.json —— 英文读法

按语义分组（greetings / people / places / things / verbs / time / brands / unit_words），分组只为方便维护，代码会合并成一张表。

```json
"english": "英格丽史",
"$50": null
```

- key 一律小写，匹配时不区分大小写
- value 是朗读时**直接替换**的中文
- 含空格的短语（`thank you`）优先于单词匹配

### 词形会自动还原

`_lookup` 会依次剥掉 `s / es / ed / ing / d / ly / er / est` 再查一次。所以补了 `run` 就不必再补 `runs / running / ran`。

不规则变化（`go/went`、`man/men`）不在自动范围内，需要各自补一条。

### 表外词怎么办

走音节兜底：双字母组合（`th→思`、`sh→什`、`tion→申`）优先，剩余字母逐个映射（`a→阿`、`b→布`），最后去掉连续重复汉字。

结果是「念得出来但可能很怪」，例如 `blizzard → 布尔伊兹阿尔德`。所有兜底词都会写进 `uncertain.jsonl`，**必须复核**。补表比改算法划算。

## 朗读化处理顺序（改代码时别打乱）

`normalize.py` 的 `run()` 顺序是有依赖的，动之前先读这张表：

| 序 | 处理 | 为什么必须在这个位置 |
| --- | --- | --- |
| 1 | 日期 `2020-01-01` | 要先吃掉日期里的连字符，否则会被第 7 步当成数值区间 |
| 2 | 时间 `12:30` | 同理，冒号不能被后面的符号清理先动 |
| 3 | 百分比 | 独立，无依赖 |
| 4 | 货币 `$50` | 要先于整数，否则 `50` 变成「五十」后货币符号就断了 |
| 5 | 单位 `5km` | 同上 |
| 6 | 分数 `3/4` | 要先于整数和除法符号 |
| 7 | 数值区间 `3~5`、连字符 | 日期已处理完，剩下的连字符才能安全判断 |
| 8 | 年份 `1998年` | 必须先于整数，4 位数才能按逐位读 |
| 9 | 运算符 `+ × ÷ =` | 必须在整数前，中文数字没法再做运算 |
| 9.5 | `2` + 量词 → 两 | 必须在整数前 |
| 10 | 序数 `1st` | — |
| 11 | 小数 | 必须先于整数 |
| 12 | 千分位 → 整数 | 最后的数字兜底 |
| 13 | 英文音译 | 放最后，避免译出来的中文再被数字规则扫到 |
| 14 | 残留符号 | `& @ #` 等 |
| 15 | 空格收尾 | 标题调用时传 `strip_cjk_space=False`，保住「第一章 雨夜」的间隔 |
| 16 | 半角引号配对 | 段内引号数为偶数才转换，奇数原样不动 |

### 加新规则时

- 数字类的，插在整数（第 12 步）**之前**，否则抢不到
- 符号类的，插在英文音译（第 13 步）**之后**，别干扰匹配
- 改完跑 `tests/sample_dirty.txt`，人工看一遍第一章输出
